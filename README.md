# Progetto fine anno 2025-2026

### Spiegazione tecnica

Questo progetto è un sito con front-end dinamico fatto con React.js che può comunicare con il back-end tramite una richiesta/e POST a vari endpoint php che, successivamente, eseguono del codice mysql per salvare dei contenuti nel database.

### funzionalità

Il progetto è un sito dove ogni utente può creare note, ogni nota ha un titolo, un contenuto (il testo) e può appartenere ad uno o più categorie.
L'utente può anche rimuovere note oppure decidere di condividerli online e saranno visibili nella pagina "Explore", dove tutti gli altri utenti possono vederli (inizialmente solo l'utente può vedere le loro note).
La pagina "Explore" è separato in categorie e puoi filtrare tra le varie categorie, così qualsiasi utente può trovare quello che cercano più facilmente.

Le sue funzionalità sono:

- pagina di registrazione (creazione account)
- pagina di login
- pagina per creazione note
- pagina per vedere le note create
- pagina Explore dove gli utenti possono convididere le loro note

## Tecnologie utilizzate per il frontend

- Vite
- React.js

- Tiptap Text Editor
- Tailwind.css

## Tecnologie utilizzate per il backend

- PHP
- MYSQL
